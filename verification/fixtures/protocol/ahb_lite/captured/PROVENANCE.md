# Captured fixtures — AHB-Lite

This directory holds traces acquired or produced from public open-source
projects. They complement the deterministic synthetic fixtures next door in
`../generated/` by exercising the decoder against real-world bus traffic.

## License allow-list

Captured fixtures must come from projects under one of these licenses:

- MIT
- BSD-2-Clause / BSD-3-Clause
- Apache-2.0
- ISC
- CC0-1.0
- public domain

GPL/AGPL/proprietary captures are excluded by policy. The static test
`test/static/captured_fixture_licenses_test.dart` walks every
`PROVENANCE.md` in the corpus and fails the build if any entry uses a
license outside this list, or if any fixture file in this directory has no
matching entry.

## Per-fixture entries

Each fixture committed below carries a block in this file with: source
project, source commit SHA, license + SPDX, author/maintainer, original
location of the testbench inside the source repo, capture method (direct
file from repo, or the exact `iverilog` / `verilator` / `cocotb`
invocation used locally), acquisition date, file size, scenario summary,
and 2–3 hand-verified anchor transactions confirmed by eye before the
snapshot was committed.

### Block template

```markdown
## `<fixture_name>.fst` — <one-line scenario summary>

- **Source project:** <project name> — <https://github.com/...>
- **Source commit:** `<sha>` (acquired YYYY-MM-DD)
- **License:** <name> (SPDX: `<identifier>`)
- **Author / maintainer:** <name>
- **Original location:** `<path/to/testbench>`
- **Capture method:** <"direct .fst from repo" | "built locally with `iverilog …`" | "built locally with `verilator --trace-fst …`" | "cocotb run: `pytest tb/… `">
- **Acquired:** YYYY-MM-DD
- **Size:** <bytes raw / bytes committed>
- **What it exercises:** <2–3 sentence scenario description>
- **Hand-verified anchors:**
  - <e.g. "write to 0x40, data 0xdeadbeef, at t≈230 ns">
  - <e.g. "burst of 4 reads starting at 0x1000">
- **Snapshot regenerated by:** `dart run tool/regenerate_captured_snapshots.dart --decoder ahb_lite --fixture <fixture_name>`
```

## Current captures

## `ahb_lite_shalan_dmac.fst` — 5 read+write SINGLE-beat pairs driven by the MS_DMAC_AHBL DMA controller

- **Source project:** Mohamed Shalan / MS_DMAC_AHBL — <https://github.com/shalan/MS_DMAC_AHBL>
- **Source commit:** `d2ea9e38e7ad9392f6675861f8cfcd3ee137c62c` (acquired 2026-05-31)
- **License:** Apache-2.0 (SPDX: `Apache-2.0`)
- **Author / maintainer:** Mohamed Shalan (AUC)
- **Original location:** `hdl/rtl/MS_DMAC_AHBL.v` and `hdl/rtl/ahbl_util.vh`.
- **Capture method:** built locally with `iverilog -g2012 -I. -o tb_ahb.vvp tb_ms_dmac_ahbl.v MS_DMAC_AHBL.v && vvp tb_ahb.vvp -fst`. Helpers + reproducible build under `test/fixtures/protocol/ahb_lite/captured/helpers/shalan/` (mirrored from the test/ tree).
- **Acquired:** 2026-05-31
- **Size:** 2053 bytes raw / 2053 bytes committed.
- **What it exercises:** A pure-Verilog testbench drives the DMAC's slave AHB-Lite port through four register writes (SADDR/DADDR/SIZE/CTRL) followed by a software trigger. The DMAC then marches through 5 word reads from `0x4000_0000…0x4000_0010` and 5 word writes to `0x5000_0000…0x5000_0010` on its master AHB-Lite port. HBURST/HRESP are tied to constants (SINGLE / OKAY) since the DMAC implements neither.
- **Hand-verified anchors:**
  - `R 0x40000000 → 0xC0FFEE00` at t=450 ns.
  - `W 0x50000008 = 0xC0FFEE08` at t=650 ns (mid-burst write).
  - `W 0x50000010 = 0xC0FFEE10` at t=810 ns (last write, CNTR runs 0…4 inclusive).
- **Snapshot regenerated by:** `REGENERATE=1 flutter test test/services/decoders/ahb_lite_captured_fixtures_test.dart`
