# Captured fixtures — AXI4-Lite

This directory holds traces acquired or produced from public open-source
projects. They complement the deterministic synthetic fixtures next door in
`../generated/` by exercising the decoder against real-world bus traffic.

## License allow-list

Captured fixtures must come from projects under one of these licenses:

- MIT
- BSD-2-Clause / BSD-3-Clause
- Apache-2.0
- ISC
- CC0-1.0
- public domain

GPL/AGPL/proprietary captures are excluded by policy. The static test
`test/static/captured_fixture_licenses_test.dart` walks every
`PROVENANCE.md` in the corpus and fails the build if any entry uses a
license outside this list, or if any fixture file in this directory has no
matching entry.

## Per-fixture entries

Each fixture committed below carries a block in this file with: source
project, source commit SHA, license + SPDX, author/maintainer, original
location of the testbench inside the source repo, capture method (direct
file from repo, or the exact `iverilog` / `verilator` / `cocotb`
invocation used locally), acquisition date, file size, scenario summary,
and 2–3 hand-verified anchor transactions confirmed by eye before the
snapshot was committed.

### Block template

```markdown
## `<fixture_name>.fst` — <one-line scenario summary>

- **Source project:** <project name> — <https://github.com/...>
- **Source commit:** `<sha>` (acquired YYYY-MM-DD)
- **License:** <name> (SPDX: `<identifier>`)
- **Author / maintainer:** <name>
- **Original location:** `<path/to/testbench>`
- **Capture method:** <"direct .fst from repo" | "built locally with `iverilog …`" | "built locally with `verilator --trace-fst …`" | "cocotb run: `pytest tb/… `">
- **Acquired:** YYYY-MM-DD
- **Size:** <bytes raw / bytes committed>
- **What it exercises:** <2–3 sentence scenario description>
- **Hand-verified anchors:**
  - <e.g. "write to 0x40, data 0xdeadbeef, at t≈230 ns">
  - <e.g. "burst of 4 reads starting at 0x1000">
- **Snapshot regenerated by:** `dart run tool/regenerate_captured_snapshots.dart --decoder axi4lite --fixture <fixture_name>`
```

## `forencich_axil_ram.fst` — 9-scenario AXI4-Lite RAM exerciser (writes, reads, stress)

- **Source project:** alexforencich/verilog-axi — <https://github.com/alexforencich/verilog-axi>
- **Source commit:** `516bd5dadc3365b7f9e225d2af8fe0b8d804fe53` (acquired 2026-05-31)
- **License:** MIT (SPDX: `MIT`) — per-file header in `tb/axil_ram/Makefile` and `tb/axil_ram/test_axil_ram.py`
- **Author / maintainer:** Alex Forencich
- **Original location:** `tb/axil_ram/test_axil_ram.py` + `rtl/axil_ram.v`
- **Capture method:** cocotb run from a clean clone of upstream — workflow + toolchain documented in the `test/` tree's [`helpers/cocotb_setup.md`](../../../../test/fixtures/protocol/axi4lite/captured/helpers/cocotb_setup.md). FST mirrored from the `test/` tree alongside the regenerated `.expected_transactions.json` snapshot.
- **Acquired:** 2026-05-31
- **Size:** 22327 bytes raw FST (well under 5 MB target; snapshot JSON is ~1 MB / 3712 transactions).
- **What it exercises:** 9 cocotb test scenarios concatenated into one FST — four write and four read scenarios over the cross-product of `cycle_pause` idle/backpressure inserters × byte-aligned vs unaligned addresses, plus a 256-outstanding-transaction stress test. Every transaction is a single-beat AXI4-Lite read or write (no bursts in the lite protocol).
- **Hand-verified anchors:**
  - First transaction at t=70 ns decodes as `W 0x0FFC = 0xAAAAAAAA [OKAY]`, wstrb=0xF — matches the testbench's first write phase.
  - Total transaction count is 3712 across 71.05 µs of sim time, all `response: "OKAY"`.
  - Last transaction at t=71050 ns is `R 0x3EF0 = 0x1A191918 [OKAY]` — final read of the 27-byte read-back at the end of the stress test's last iteration.
- **Snapshot regenerated by:** `REGENERATE=1 flutter test test/services/decoders/axi4lite_captured_fixtures_test.dart`
