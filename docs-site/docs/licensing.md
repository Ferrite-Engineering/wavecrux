# Tiers & licensing

Licensing terms are the same for all four EDACrux products — WaveCrux, NetCrux,
LintCrux and SimCrux — so they live in one place on the suite site:
**[edacrux.app/licensing](https://edacrux.app/licensing)**.

That page covers the Open Core, Pro, Enterprise and Education tiers, how license
keys work, and what changes between the public beta and 1.0.

The short version: through the 0.8.x public beta every tier is unlocked for
everyone and no license keys are issued, so nothing described in this guide is
gated. From 1.0 the tiers take effect — Open Core stays free, needing no
account, no key and no network call of any kind, while Pro and Enterprise
features need a license key. The badges are how you tell which is which, in
either build.

Throughout this guide, a badge beside a heading or feature name marks the tier it
needs: <span class="tier tier-pro">Pro</span>,
<span class="tier tier-enterprise">Enterprise</span> or
<span class="tier tier-edu">EDU</span>. Anything without a badge is Open Core.
